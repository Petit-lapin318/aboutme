Проекты

Интернет-магазин на Django

Полноценный интернет-магазин с авторизацией, корзиной и админкой. Реализован бэкенд на Django, фронтенд — на базовых HTML/CSS. Использовалась PostgreSQL для хранения товаров и пользователей. Проект создан в рамках учебного курса, но доработан мной для понимания архитектуры фреймворка.

Приложение для Bitrix24

Локальное приложение для CRM-системы Bitrix24. Позволяет загружать список сделок, фильтровать по сумме и отображать в таблице. Написано на чистом JavaScript с использованием официального SDK Bitrix24. Установлено и работает на тестовом портале.

Telegram-бот с AI

Бот, который принимает текст от пользователя и отправляет его в AI-сервис для анализа или генерации ответа. В планах — подключить LLM (например, через Ollama или OpenRouter). Бэкенд на Python (FastAPI), запускается локально. Позже будет задеплоен в облако.

Gameify Life — RPG для жизни

Приложение, которое превращает реальную жизнь в видеоигру: ежедневные задачи дают XP, долгосрочные цели — уровни. В разработке: бэкенд на FastAPI + PostgreSQL, фронтенд на React. Цель — научиться fullstack-разработке на реальном проекте.
